# Antigravity-Hans 自定义翻译名单（可选，进阶用法）
#
# 提示：只想让权限模式、模型等级等选项名显示英文时，无需本文件——
#       双击或右键右下角悬浮按钮，勾选「选项名保留英文」即可。
#
# 用法：把本文件复制（或重命名）为 custom-translations.txt，放在 antigravity-hans 程序同一目录下。
# Windows 需显式信任名单：启动时附加 --trust-custom-translations；
# 创建快捷方式时也可附加该选项，以便之后通过快捷方式加载名单。
# 修改后先用 --stop 结束旧监视器，再重新运行汉化，无需重启应用。
# 静态补丁需先关闭 IDE，然后重新执行“注入静态汉化”。本名单优先于内置预设。
#
# 两种写法（一行一条，# 只能写在行首作为注释）：
#   英文原文              → 保留英文，不翻译
#   英文原文 = 你的译文    → 使用你自己的译文
#
# 注意：按“整段文字”匹配（不区分大小写）。例如写 Default 后，界面上所有恰好是 “Default”
#       的文字都会受影响；长句中间出现的 Default 不受影响。

# 示例：保留英文
Request Review

# 示例：换成自己的译法
Turbo = 快速模式
