# Antigravity 2.31.0 与 IDE 2.6.0 内核适配

## 修改

- 为普通版 Swarm 面板增加专用汉化脚本，覆盖标签、空状态、筛选、回放和已确认的任务状态等界面文案。监视器仅对符合已核实地址和页面标记的面板注入，页面导航后会重新校验；此面板不加载外部词库或个人翻译名单。
- 共用词库新增 85 条静态界面文案，覆盖权限、遥测、额度、工作区、智能体操作和状态等；Gemini 4 Carbon 保留模型名称，并翻译推理强度及相关状态。
- 翻译已确认的协调员欢迎语和活动记录模板，保留项目名、查询内容、文件路径、URL、工具名与命令。Swarm 的成员名称、消息正文和原始数据不参与翻译。
- Windows 本地构建脚本在构建前后校验两份内嵌汉化脚本，并输出各自的 SHA-256。

## 验证与限制

- 在 Windows 上核对了 Antigravity 2.31.0 和 IDE 2.6.0 的运行版本及智能体前端。普通版 Swarm 的空状态和标签已在实际页面进行可恢复测试，并验证了跨页面消息往返；活跃群组中的状态与数量文案依据前端资源核对，并由自动化测试覆盖。
- IDE 的智能体前端已核对；由于本次没有捕获到 IDE 内的 Swarm 页面，尚不能确认其页面地址及 Swarm 面板的实际注入效果。其他未打开的页面与未来版本仍可能出现英文；macOS 未实机验证。
- 普通版 Swarm 面板需要动态监视器持续运行。切换语言时，专用面板通过已确认的来源与父窗口同步；`/swarm` 命令及动态数据保持原样。
- 自动化检查包括词库 lint、JavaScript 回归测试、Go 静态检查与单元测试，以及 macOS ARM64 交叉编译。词库 lint 的既有警告涉及命令、路径和产品名称等保留英文内容。
